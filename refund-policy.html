Refund Policy

1. Booking Cancellation by User

  • 24 hours se zyada pehle cancel → 100% refund (minus payment gateway charges)
  • 12–24 hours pehle cancel → 75% refund
  • Less than 12 hours → No refund (pandit already prepare ho chuka hota hai)

2. Cancellation by Pandit / Platform

  • Pandit last moment unavailable → 100% refund + 10% discount next booking pe
  • Technical issue (payment fail, wrong pandit) → Full refund within 3–5 days

3. Refund Process

Refund request admin dashboard se approve hone ke 3–7 working days me original payment method pe return ho jayega.

Razorpay gateway charges deduct ho sakte hain (usually ₹2–5).

4. No Refund Cases

  • Puja complete hone ke baad complaint (service dissatisfaction ke alawa)
  • User ne pandit ko galat address diya ya late tha
